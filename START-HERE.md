# Start here

Thanks for coming to our LA Tech Week talk! This folder holds the whole thing: the engine, the deck we presented, and a builder to make your own. Choose a path.

## 1. Watch the talk (30 seconds)

Double-click **`index.html`** in this folder and choose **"Play the One Giant Leap talk"**. Press the **right arrow** or **space** to move forward, and **F11** (Windows) or **⌃⌘F** (Mac) for fullscreen.

You don't need an install or an account, and it works offline.

## 2. Build your own deck, no code (about 20 minutes)

From the same launcher, open **PixelDeck Studio**. It walks you through six steps:

1. **Brief:** who's in the room and the one thing you want them to believe
2. **Shape:** pick a story structure
3. **Look:** pick a visual style
4. **Storyboard:** fill in each scene
5. **Rehearse:** run through it with timing
6. **Save & export:** get a single `.html` file you can present anywhere

## 3. Build it with an AI coding assistant (best results)

This folder is set up so **Claude Code** or **Codex** can act as your guide. They read `CLAUDE.md` / `AGENTS.md`, which explain how everything works.

**If you don't use the terminal:** in the Claude desktop app, open a new task and connect this folder (you need a paid Claude plan).

**If you do:**
```bash
cd pixeldeck
claude        # or: codex
```

Then paste this:

> I just got this project from One Giant Leap. Help me make a presentation for my business. Ask me a few questions first.

It will interview you, pick a structure and a look, write the scenes, and show you how to present the result.
